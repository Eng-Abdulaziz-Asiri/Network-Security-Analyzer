# 🛡️ Network Security Analyzer

A Python & Bash tool that runs Nmap scans, analyzes port risks, and generates a professional dark-themed HTML security report.

## ⚙️ Requirements
- Linux OS
- Python 3
- Nmap (`sudo apt install nmap`)

## 🚀 How to Run

### Bash Version:
```bash
chmod +x analyzer.sh
sudo ./analyzer.sh
